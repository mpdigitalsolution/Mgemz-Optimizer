# Icons for PromptPerfect Chrome Extension

This directory should contain the following icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (toolbar icon, high DPI)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Design Guidelines

The icons should follow these design principles:

1. **Simple and Recognizable**: Use a clean, minimal design
2. **Consistent Style**: All icons should use the same visual style
3. **Good Contrast**: Ensure visibility on both light and dark backgrounds
4. **Scalable**: Design should work well at small sizes

## Suggested Icon Concepts

- **Sparkle/Wand**: ✨ (magic/improvement)
- **Lightning Bolt**: ⚡ (speed/optimization)
- **Arrow Up**: ⬆️ (improvement/better)
- **Star**: ⭐ (quality/perfection)
- **Gear**: ⚙️ (settings/optimization)

## Color Scheme

Suggested color palette:
- Primary: Purple/Blue gradient (#667eea to #764ba2)
- Background: White or transparent
- Accent: White or light colors for contrast

## Creating Icons

You can create these icons using:
- **Figma** (free design tool)
- **Adobe Illustrator** (vector graphics)
- **Sketch** (Mac design tool)
- **Online icon generators**

## File Format

- Use PNG format with transparency
- Ensure proper alpha channel for transparency
- Optimize file sizes for faster loading

## Example Design

A simple design could be:
- Background: Gradient circle (blue to purple)
- Foreground: White sparkle or wand icon
- Clean, modern aesthetic that matches the extension's UI
