Install in Developer Mode

Load the extension locally from source

1
Open Chrome Extensions
Type chrome://extensions in the address bar and press Enter.
2
Enable Developer Mode
Toggle the Developer mode switch in the top-right corner.
3
Load Unpacked
Click "Load unpacked" and select the extension folder:
E:\Ai build\PROMP mASTER
4
Verify Installation
The extension icon (✨) appears in the toolbar. Click it to open the settings popup.
5
Configure API Key
Select your AI model provider from the dropdown, enter your API key, and click Save Settings.
💡 Need detailed instructions? See the full guide in INSTALL_DEV_MODE.md included with the extension files.
