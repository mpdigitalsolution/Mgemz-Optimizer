📋 Test Instructions
Follow these steps to test the PromptPerfect extension:
  1. Load the extension: Open Chrome Extensions page (chrome://extensions/), enable Developer mode, and load the extension folder.
  2. Configure API key: Click the extension icon and enter your DeepSeek API key.
  3. Test on real platforms: Visit DeepSeek Chat or Grok.
  4. Type a prompt: Write any prompt in the input field.
  5. Click Optimize: The "✨ Optimize" button should appear.
  6. Review results: The optimized prompt should replace your original text.
  7. Test keyboard shortcut: Use Ctrl+Shift+O (Cmd+Shift+O on Mac).
  8. Check history: Open the extension popup to see your optimization history.
Note: This test page only demonstrates the UI and workflow. The actual optimization happens via the DeepSeek API when the extension is properly installed and configured.
